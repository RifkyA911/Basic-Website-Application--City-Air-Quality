## 🇬🇧 English

A simple website displaying air quality index (AQI) information for a city. Built with pure HTML, CSS, and JavaScript — no frameworks.

### ✨ Features
- 📊 Air Quality Index (AQI) display
- 🌫️ Pollutant parameters (PM10, PM2.5, etc.)
- 📱 Simple responsive design

### 🚀 Getting Started
1. Clone the repository
2. Open index.html in your browser

### 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript (vanilla)
- **Data:** Static sample dataset

> This was my first project learning web development.
